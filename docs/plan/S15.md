# S15 — Delivery: UI, README, AI_USAGE, demo, final verification (plan v2, phase E)

Goal: a reviewer can clone, run one command, watch a demo, and understand every decision. A small, polished UI shows the product: upload with live status, a cited brief per document, and streaming chat with clickable citations that open the exact source sentence.

Supersedes S9 (re-scoped to a minimal UI) and S10.03–S10.11. The UI lane starts once the S13.01 SSE contract and the S12.05 brief API are merged. The docs tasks run last, with real numbers.

UI stack: Vite + React + TypeScript, served by FastAPI at `/app` from a prebuilt `frontend/dist` (`make ui`), with no SSR. Auth is the API key typed on a settings screen and kept in `localStorage`. This is documented as a demo assumption; production would use sessions (design §16). Styling is plain CSS with design tokens; no component library is needed. Accessibility baseline: keyboard reachable, visible focus, labels.
