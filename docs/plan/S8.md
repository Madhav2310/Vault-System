# S8 — Compare Matrix (Tier B)

Goal: a documents × questions grid where each cell is a cited, coverage-stated mini-run executed in the background lane, streamed as it completes, idempotent, and exportable.
Starts only after all Tier A tasks are done (README slice rules).
