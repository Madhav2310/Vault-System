# S22 — Accuracy and speed changes, one at a time, each proven on the S21 set (plan v4)

Goal: move answer correctness, faithfulness and citation precision up, and time to first token down, with every change accepted only by a paired test on the S21 v2 set. Ranking from `docs/research/reports/High accuracy cited document QA.md` (implementation order table).

Rules for every task in this slice:
- **One change per task, one A/B per task.** Train for development, dev for the decision (paired, clustered CI, MDE printed), test only at the S22 gate.
- **Acceptance rule:** adopt if the primary metric improves with the paired CI excluding 0, OR it is non-inferior (CI lower bound > −2 points) and the task's secondary metric (latency or cost) improves; injection violations stay 0 and abstention correctness does not drop. Otherwise revert the default and record the result.
- **Attribution first:** each task names the S21.08 stage it targets; report that stage's count before and after.
- **Budget:** each A/B ≤ $1 unless stated. Prompts change only by new version files.
- **Machine:** one eval at a time; rebuild the stack once per task.

### S22.01 — Chunker@2: structure-aware boundaries
Deps: S21.11 · Design: §6.4 · Files: `backend/app/ingestion/chunker.py`, `backend/app/ingestion/chunk_rules.py`, `backend/tests/unit/ingestion/test_chunker_v2.py`
Targets: `chunking`, `retrieval` stages (10-K tables, papers).
Do:
1. Cut at headings and table boundaries first, then by tokens (target 350, max 600).
2. **Tables whole** up to 1,200 tokens; a longer table splits by rows with the header row repeated in each piece's *index text* (not in `original_text`). Each table row stays one sentence handle, so a row can be cited.
3. Store `section_path` (heading chain) and table caption per chunk.
4. Figure/table captions get their own small chunk linked to the table.
5. Overlap is a separate arm (`chunker@2-overlap25`): 25% of the previous chunk's sentences added to index text only.
6. Evidence stays the glyph-mapped `original_text` (invariant I1); only boundaries change.
- [ ] AC1 A table never spans two chunks below 1,200 tokens; split tables repeat headers in index text only — `t:unit/ingestion/test_chunker_v2.py::test_tables`
- [ ] AC2 `original_text` of every chunk is an exact slice of the glyph stream (I1) — `t:unit/ingestion/test_chunker_v2.py::test_invariant_i1`
- [ ] AC3 Paired A/B on dev: `retrieval` stage failures down and answer_pass non-inferior, with the overlap arm decided separately — `$ grep -c "chunker@2" docs/evidence/s22_ab.md` ≥ 2
Evidence: A/B rows.
