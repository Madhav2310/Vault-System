### S5.12 — Capacity simulation at 100 concurrent users (calibrated, not run at full scale)
Deps: S5.06–S5.11 · Design: §13.3, research 04 §7 · Files: `loadtest/sim/model.py`, `loadtest/sim/calibrate.py`, `docs/loadtest-report.md`
Do: Per user decision, the 100-user test is **simulated**. (1) Run a real 10-user Locust test against FakeProvider to measure per-component service times (API overhead, DB, reranker, queue waits). (2) Build a discrete-event model (SimPy) of the system: API workers, DB pool, reranker workers, provider token buckets with Start-tier limits, Celery queues. (3) Validate the model by predicting the 10-user run. (4) Simulate 10 → 100 → 150 users, a 500-file upload burst, and a 429 storm.
- [ ] AC1 Calibration run at 10 users completes with zero failures and per-component latencies recorded — `$ make loadtest USERS=10 DURATION=5m` exits 0 and writes `loadtest/out/service_times.json`
- [ ] AC2 Model validation: simulated 10-user TTFT p50/p95 within ±15% of measured — `$ python loadtest/sim/calibrate.py --validate` exits 0
- [ ] AC3 Simulated TTFT overhead p95 at 100 users < 500 ms [T] — `$ python loadtest/sim/model.py --users 100` prints `ttft_overhead_p95_ms` < 500
- [ ] AC4 Simulated DB pool wait p95 at 100 users < 50 ms [T] — `$ python loadtest/sim/model.py --users 100 --metric db_pool_wait_p95_ms` prints < 50
- [ ] AC5 Simulated upload burst: chat TTFT p95 rises < 20% vs no burst [R] — `$ python loadtest/sim/model.py --users 100 --burst 500` prints `burst_ttft_regression_pct` < 20
- [ ] AC6 Simulated oldest ingestion job age during a 3× upload rate < 5 min [T] — `$ python loadtest/sim/model.py --users 100 --upload-rate 3x --metric oldest_job_age_s` prints < 300
