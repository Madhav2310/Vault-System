# S20 — Delivery: README, architecture, evaluation, AI_USAGE, demo, final verification (plan v3)

Goal: a reviewer with 5–20 minutes clones the repo, runs one command, watches a 3–5 minute demo, and understands every major decision and its evidence.

Research (report §8):
- reviewers check runnability first
- docs are missed in about 80% of submissions
- AI-tool use is judged on judgement: where the AI was wrong and how it was caught
- over-engineering is penalized, so justify every heavy piece with a number or mark it optional

Supersedes S15.06–S15.12 (reference text in `docs/plan/S15.md`); **this file wins**. The README skeleton was started in S16.06 and is extended here.
