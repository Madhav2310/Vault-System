# S3 — Grounded chat (non-streaming) and the evidence ledger

Goal: multi-turn chat that answers from retrieved evidence with sentence-level application-managed citations, persists a complete evidence ledger per turn, and meets the grounding targets on the golden set.

Pipeline in this slice (no routing or gate yet): `guard → load_memory → analyze_query → retrieve → rerank → expand → generate → resolve_citations → persist → release_turn`.
