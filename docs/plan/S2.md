### S2.18 — LLM judges and interim agreement check
Deps: S2.13, S0.13 · Design: §18, §19 · Files: `backend/prompts/eval_judge_faithfulness@1.md`, `eval_judge_citation@1.md`, `eval_judge_completeness@1.md`, `eval_judge_rubric@1.md`, `eval/judge.py`
Do: Judges run on role `deep` (primary) and, on a sampled subset, `flagship` (secondary), with structured verdicts and a confidence field. The judge shares the generator's vendor, so bias is controlled by (1) deterministic graders running first and judges only filling the gaps, (2) reference-guided grading against gold quotes, (3) the judge never seeing the generator's model name, (4) judge tier ≥ generator tier, and (5) the human-labelled agreement check in S10. Human labelling is deferred to the final review (S10, user decision); until then judge reliability is checked by **inter-judge agreement** on a sample, and the tuner relies on deterministic graders wherever an item allows it.

- [ ] AC2 Primary–secondary judge agreement ≥ 0.80 per judge type on a 20-item train sample per type [T] — `$ python -m eval.judge --inter-judge --sample 20` prints each ≥ 0.80
- [ ] AC3 Items where the judges disagree are marked `grader_suspect` and excluded from tuner accept/reject decisions — `t:unit/eval/test_judge.py::test_disagreement_marked`
- [ ] AC4 Judge tier is at least the generator tier and judge inputs never contain the generator's model name (config + recorded-input check) — `t:unit/eval/test_judge.py::test_judge_tier_and_blind`
