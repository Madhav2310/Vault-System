# eval: evaluation harness

Run from the repository root through the `make eval*` targets (cost-capped; sample, never run the full set to
validate a change). The method, the results and the runbook are in `docs/evaluation.md`.

**Dataset** (`datasets/vault_eval/`): 311 live items with atomic claims and sentence-range gold (schema in
`schema.py`, loaded by `loader.py`), a deterministic train / dev / test split by source document (`splits.py`),
the document map (`documents.yaml`, generated by `build/build_docs.py`) and the audit record
(`audit_queue.yaml`). Third-party sources live in gitignored `sources/` (`make eval-fetch`).

**Runner**: `run.py` answers the items of one split through a pluggable pipeline (`pipeline_http.py` = the
running stack, `pipeline_retrieval.py` = retrieval only, no chat model), maps gold to chunks (`mapping.py`),
grades deterministically (`graders.py`), judges (`judge.py`: claims, support, abstention; versioned prompts),
and writes the report (`report.py`) and the answers file (`answers_dump.py`). `sse.py` times the SSE stream.

**Analysis**: `rejudge.py` (re-judge stored answers; writes beside its input or in `--out-dir`, never replaces a
result without `--overwrite`), `attribution.py` (one earliest faulty stage per failed item), `paired.py` (A/B;
`--ledger` lists the items gained and lost), `gate.py` (CI gate tiers), `fingerprint.py` (what a run measured, so
only like runs are compared), `diagnose.py` (where a run's gold passages were lost), `baseline.py` (freeze and
compare).

**Contamination** (`contamination.py`): no default prompt or judge may share a word 5-gram or a proper name with any
gold item, in any split (`python -m eval.contamination`; in CI through `backend/tests/unit/eval/test_contamination.py`).

`labels/` holds 200 human-labeled pairs; calibration of the current judge versions against them has not been run (docs/evaluation.md, runbook step 7).

**Build** (`build/`): `fetch_sources.sh` downloads the third-party sources; `sample_public.py` samples strata 1-6
from them; `build_docs.py` writes the document map; `audit.py`, `apply_audit.py` run the gold audit;
`check_coverage.py` checks the stratum matrix.

**What writes what**: `reports/<run_id>.md|.json` (report.py), `reports/<run_id>.answers.jsonl` (answers_dump.py),
`reports/<run_id>.rejudged.json` (rejudge.py), `baselines/<name>.json` (`--freeze`), dataset files (build/*).
`baselines/final/` keeps the four final run reports, `baselines/answer.json` is the final dev run and
`baselines/retrieval.json` the frozen retrieval-only baseline.

Invariant: a behaviour change is accepted only through a paired dev-split decision; never tune on test-split content.
